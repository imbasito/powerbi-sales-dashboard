# Power BI Project: Chocolate Sales Dashboard

This project showcases an end-to-end interactive dashboard created using Power BI and real data from the "Awesome Chocolates" SQL database.

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- MySQL (as data source)

## Features Implemented
- Drill-down and drill-through navigation
- Slicers, buttons, and custom tooltips
- KPI cards using DAX (Revenue, Top Product, Monthly Sales)
- Conditional formatting for trends and alerts
- Responsive layout for report presentation

## Folders
- `/dashboard` → Power BI `.pbix` file
- `/images` → Screenshots of the dashboard
- `/DAX` → Text files with custom measures

## Screenshot Preview
![Dashboard](images/dashboard_main.png)

##  Key Insights
- Product-wise revenue breakdown
- Monthly trends and seasonal spikes
- Performance by region and category

## Outcome
Built a report ready for business stakeholders with complete interactivity, data storytelling, and live connection to MySQL.
